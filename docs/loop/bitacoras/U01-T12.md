### Cambio
- `report_closed.py`:
  - H-02: `|` solo dentro de un grupo (profundidad de paréntesis mayor que 0).
  - AMARILLO: el patrón debe compilar con `re`, los paréntesis cuadran y un cuantificador (`*`, `+`, `{n,m}`) sobre un grupo que ya contiene otro, directo o anidado, se rechaza (ReDoS). `(…)?` con cuantificador interno se admite.
  - H-03: un nodo se cierra con `type`, `$ref`, `enum` o `const`. `allOf` cierra si alguna rama cierra (recursivo); `anyOf` y `oneOf` cierran solo si todas las ramas cierran y la lista no está vacía. `unevaluatedItems` y `unevaluatedProperties` abiertos se rechazan como `items`.
