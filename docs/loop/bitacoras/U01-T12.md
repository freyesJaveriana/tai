- `contracts/src/veridicus_contracts/checks/report_closed.py`
  - F-02: los patrones se juzgan por lo que aceptan. Cada fragmento (clase, escape o carácter) se prueba con un espacio, un tabulador, un NBSP y un salto de línea.
